# 🔴 Liverpool FC Fan Messenger - Kazakhstan

Эксклюзивное мессенджер-приложение для фанатов футбольного клуба Ливерпуль в Казахстане.

## 📱 О приложении

**Liverpool FC Fan Messenger** - это комплексное iOS приложение, созданное специально для казахстанских фанатов Liverpool FC. Приложение объединяет общение, актуальную информацию о клубе, партнерские предложения от спортивных магазинов и организацию совместных просмотров матчей.

### ✨ Основные возможности

#### 💬 Чат для фанатов
- Общение в реальном времени с другими фанатами по всему Казахстану
- Обсуждение матчей, новостей клуба и футбольных событий
- Дружелюбное сообщество единомышленников

#### ⚽ Матчи и турнирные таблицы
- **Текущие турниры**: Английская Премьер-лига и Лига Чемпионов
- **Онлайн таблицы**: Актуальные позиции в турнирах
- **Текстовые трансляции**: Комментарии матчей минута за минутой
- **Расписание матчей**: Все предстоящие игры Liverpool FC
- **Статистика**: Подробная статистика матчей

#### 🛍️ Спортивные магазины
- **Партнерские магазины**: Сеть спортивных магазинов по всему Казахстану
- **Эксклюзивная скидка 10%**: При заказе через приложение
- **Оригинальная продукция**: Футбольная форма, аксессуары, сувениры
- **Города**: Алматы, Нур-Султан и другие города
- **Партнеры**: Спорт Мастер, Nike Store, Adidas, Decathlon

#### 📢 Доска объявлений
- **Сборы в пабах**: Информация о просмотрах матчей в пабах
- **Местоположение**: Карты и адреса заведений
- **Счетчик участников**: Сколько фанатов уже идут
- **Обмен билетами**: Продажа и обмен билетов на матчи
- **Общие объявления**: Новости фан-движения

#### 👤 Профиль и подписка
- **Годовая подписка**: 15,000 ₸ в год (~1,250 ₸/месяц)
- **Управление профилем**: Персональная информация
- **Статистика**: Ваша активность в приложении
- **Настройки**: Уведомления, язык интерфейса

### Технологический стек

- **Framework**: SwiftUI
- **Минимальная iOS**: 16.0
- **Архитектура**: MVVM
- **State Management**: Combine + @StateObject/@ObservableObject
- **Навигация**: NavigationView + TabView
- **Подписки**: StoreKit (In-App Purchase)

## 🚀 Установка и запуск

### Требования
- macOS 13.0+
- Xcode 15.0+
- iOS 16.0+ (для запуска на устройстве)

### Шаги установки

1. **Клонировать репозиторий**
```bash
git clone <repository-url>
cd LiverpoolFanApp
```

2. **Открыть проект в Xcode**
```bash
open LiverpoolFanApp.xcodeproj
```

3. **Выбрать целевое устройство**
   - Simulator: iPhone 14 Pro или новее
   - Physical device: Подключите iPhone

4. **Запустить приложение**
   - Нажмите ⌘ + R или кнопку Run
