# Glow·Up — мобильное приложение для записи к beauty-мастерам и фотографам

Кроссплатформенное приложение для **iPhone и Android** (React Native + Expo, один код на обе платформы).
Клиент выбирает услугу, мастера, дату и время, формат (выезд на дом или студия) и записывается.

## Что умеет

- **12 категорий, 60+ услуг** с ценами в тенге: маникюр, педикюр, волосы, барбер, брови и ресницы,
  макияж, косметолог, массаж и SPA, депиляция, **фотосессии**, **видеосъёмка**, **образ под ключ**
  (фотосессия + визажист + укладка, образ невесты и т.д.).
- Доп. опции к услуге (аренда студии, доп. час съёмки, ретушь, визажист, дрон…) — пересчёт итоговой цены.
- Мастера с рейтингом, отзывами и уровнем: «Мастер» и «Топ-мастер» (+25% к цене).
- Запись: мастер → дата (14 дней вперёд) → свободное время → выезд/студия → контакты → оплата
  (Kaspi / карта / наличные) → промокод (`GLOW10` −10%, `FIRST15` −15%).
- Мои записи (предстоящие / история, отмена), избранные мастера, профиль, выбор города, поиск по услугам.
- Данные сохраняются на устройстве (AsyncStorage).

## Где менять прайс

Все услуги, цены, доп. опции, мастера, промокоды, стоимость выезда — в одном файле
[`src/data/catalog.ts`](src/data/catalog.ts). Цены сейчас ориентировочные (рынок Алматы/Астаны) —
сверьте с вашим прайсом.

## Запуск

```bash
cd BeautyApp
npm install
npx expo start        # отсканируйте QR в приложении Expo Go (iOS/Android)
```

Проверки: `npm run typecheck`.

## Публикация в App Store и Google Play

Через EAS (облачная сборка, Mac не нужен):

```bash
npx eas-cli@latest login
npx eas-cli@latest build --platform all --profile production
npx eas-cli@latest submit --platform ios      # нужен Apple Developer ($99/год)
npx eas-cli@latest submit --platform android  # нужен Google Play Console ($25 разово)
```

Bundle ID / package: `kz.glowup.app` (в `app.json`, замените на свой). Иконки — в `assets/`.

## Структура

```
src/
  app/                 экраны (Expo Router: файл = экран)
    (tabs)/            Главная, Каталог, Мастера, Мои записи, Профиль
    category/[id]      услуги категории
    service/[id]       карточка услуги и цены
    master/[id]        профиль мастера и его прайс
    booking/[serviceId] оформление записи
    booking-success    подтверждение
  components/ui.tsx    общие компоненты
  data/catalog.ts      каталог, цены, мастера
  store/AppStore.tsx   записи, избранное, профиль
```

## Следующие шаги для «боевого» запуска

Сейчас это клиентское приложение без сервера: записи хранятся только на телефоне клиента, а занятые слоты
генерируются демо-логикой. Для реальной работы нужно:

1. Бэкенд (например Supabase/Firebase или свой API): мастера, расписание, записи, отзывы.
2. Авторизация по SMS-коду.
3. Приложение/кабинет мастера и админ-панель (подтверждение записей, управление прайсом).
4. Push-уведомления о записи и напоминания.
5. Онлайн-оплата (Kaspi Pay / платёжный шлюз).
