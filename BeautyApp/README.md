# Aray — образ и съёмка с выездом

**Aray** (каз. «арай» — сияние, отблеск зари) — мобильное приложение для **iPhone и Android** (React Native + Expo).
Визажист, стилист, фотограф и мобилограф приезжают к клиенту: образ, бэкстейдж сборов и готовые Reels в одной записи.

## Услуги

Только макияж, причёски, фото, видео и бэкстейдж. Выезд по городу включён в цену.

| Пакет | Что входит | Цена |
|---|---|---|
| Aray Base | Макияж + причёска/укладка Dyson | 35 000 ₸ |
| **Aray Star** | Base + мобилограф снимает сборы + Reels за 48 ч | 65 000 ₸ |
| Aray Icon | Star + фотограф 1 ч, 20 фото в ретуши, 2 Reels | 120 000 ₸ |
| Утро невесты | Пробный образ, свадебный образ, фото + видео сборов, клип | от 190 000 ₸ |

Отдельно: макияж (15–45 тыс.), причёски (15–30 тыс.), фотосъёмка (20–220 тыс.), видео и Reels (20–250 тыс.),
бэкстейдж (сборов, фотосессии, утра невесты — 30–90 тыс.) и доп. опции (ранний выезд, пробный образ,
доп. час, студия, ретушь, дрон, экспресс-монтаж).

Весь прайс, команда, поводы, FAQ, промокоды (`ARAY10`, `FIRST15`) и номер WhatsApp — в
[`src/data/catalog.ts`](src/data/catalog.ts).

## Экраны

- **Главная** — тёмный hero, витрина пакетов, сравнение Base/Star, «Как это работает», категории,
  поводы (свадьба, қыз ұзату, той…), команда, FAQ.
- **Услуги** — полный прайс с фильтром по категориям.
- **Команда** — визажисты, стилисты, фотографы, мобилографы; избранное; страница специалиста.
- **Запись** — специалист → дата (30 дней) и время (с 7:00, не раньше чем за 3 ч) → адрес → повод →
  доп. опции → контакты → Kaspi/карта → промокод → итог.
- **Записи** — предстоящие и история, отмена. **Профиль** — контакты, город, бонусы, поддержка.

## Запуск

```bash
cd BeautyApp
npm install
npx expo start        # QR-код → Expo Go на телефоне
npm run typecheck
```

## Публикация

```bash
npx eas-cli@latest build --platform all --profile production
npx eas-cli@latest submit --platform ios       # Apple Developer, $99/год
npx eas-cli@latest submit --platform android   # Google Play Console, $25 разово
```

Bundle ID / package: `kz.aray.app` (в `app.json`). Иконки и сплэш — в `assets/`.

## Что нужно для боевого запуска

Сейчас данные хранятся на устройстве, а занятость мастеров — демо. Нужны: бэкенд (Supabase/Firebase) для
записей и расписания, вход по SMS, кабинет мастера и админка, push-уведомления, оплата через Kaspi Pay,
реальные фото и видео работ вместо графических заглушек.
